# Borderlands 2 Android: соответствие ПК-версии и исходные данные для исследования DLC

Дата исследования: 2026-10-19.

## Основной вывод

Оригинальная мобильная Borderlands 2 из этого проекта основана на игровой ветке **1.8.4**. В нативной библиотеке игровая версия записана как **`1.8.4W`**. Настольному обновлению 1.8.4 соответствует дата **29 октября 2015 года**. В оригинальном Android-бинарнике присутствуют даты компиляции июля 2016 года.

Корректное описание сборки:

> Borderlands 2 для Android/SHIELD, основанная на ПК-ветке 1.8.4 (`1.8.4W`), с отдельными платформенными изменениями и сокращённым комплектом контента; бинарник скомпилирован в июле 2016 года.

Уверенность в определении игровой ветки высокая: проверена и строка версии, и её использование при инициализации `GGameVersion`. Полное совпадение поведения с ПК-патчем 1.8.4 не устанавливалось.

## Исследованные оригинальные файлы

Исследовались исходные поставочные файлы, чтобы изменения восстановленного порта, русификации и ARM64-моста не повлияли на определение исторической версии.

| Файл относительно корня проекта | Назначение |
| --- | --- |
| `original/base.apk` | Исходный Android-пакет и нативная библиотека |
| `original/main.31.com.tt2kgames.Borderlands2.obb` | Оригинальный основной контейнер ресурсов |
| `original/patch.31.com.tt2kgames.Borderlands2.obb` | Оригинальный дополнительный контейнер ресурсов, конфигураций и игровых пакетов |

Библиотека внутри APK: `lib/armeabi/libUnrealEngine3.so`.

Размер оригинальной библиотеки: **49 885 152 байта**.

SHA-256 оригинальной библиотеки:

```text
7857316c39c0421ae421553bf34c387e53ff671da759bb83c42fe79e1e17264d
```

Корневая `libUnrealEngine3.so` на момент исследования имеет другой SHA-256 и уже изменена. Для повторения исторического анализа следует брать библиотеку непосредственно из `original/base.apk`.

## Подтверждённые технические признаки

| Признак | Значение | Интерпретация |
| --- | --- | --- |
| Android package | `com.tt2kgames.Borderlands2` | Идентификатор приложения |
| Android `versionName` | `1.0.0.0.33` | Собственная нумерация мобильных релизов |
| Android `versionCode` | `33` | Номер мобильной сборки; не номер ПК-патча |
| `GGameVersion` | `1.8.4W` | Прямой маркер игровой ветки 1.8.4 |
| `GBuiltFromChangeList` | `1134170` | Внутренний идентификатор сборки исходного кода |
| `GEngineVersion` | `8636` | Внутренняя версия движка UE3 |
| `GPackageFileVersion` | `833` | Версия сериализации игровых пакетов |
| `GPackageFileGameVersion` | `26` | Отдельный внутренний номер версии игровых данных |
| Заголовки проверенных cooked-пакетов | `833 / 46` | File version / licensee version |
| Строки дат компиляции | `Jul 3 2016`, `Jul 6 2016` | Даты присутствуют в разных частях исходной библиотеки |

Версии пакетов `833 / 46` проверены у `WillowGame.xxx`, `GD_Siren_Streaming_SF.xxx` и `Startup.xxx`. Это не утверждение, что отдельно проверен каждый пакет обоих OBB.

В `Coalesced_INT.bin`, в секции `OnlineSubsystemSteamworks.OnlineSubsystemSteamworks` файла `Android-WillowEngine.ini`, также присутствует `GameVersion=1.0.0.0`. Это отдельное конфигурационное значение; его нельзя подменять им игровую версию `GGameVersion`.

### Связь строки версии с кодом

Адреса относятся к оригинальной 32-битной ELF-библиотеке из APK:

| Объект | Виртуальный адрес |
| --- | --- |
| Строка `1.8.4W` с завершающим NUL | `0x02BB9BDC` |
| Глобальная переменная `GGameVersion` | `0x02F919B4` |
| `GBuiltFromChangeList` | `0x02F3C158` |
| `GEngineVersion` | `0x02F3C15C` |
| Участок подготовки аргументов и вызова конструктора версии | `0x00E838BC`–`0x00E838C8` |

Проверено, что участок инициализации передаёт строку по адресу `0x02BB9BDC` конструктору объекта по адресу `0x02F919B4`. Следовательно, это используемое значение `GGameVersion`, а не случайная неиспользуемая строка в ресурсах. Значение суффикса `W` отдельно не устанавливалось.

## Сопоставление с историей настольных обновлений

В официальной истории настольной версии Aspyr **1.8.4 датирована 29 октября 2015 года**. Следующая указанная версия, 1.8.5, относится к 2019 году:

- [Официальная история версий Aspyr в Mac App Store](https://apps.apple.com/qa/app/borderlands-2/id570316450?mt=12).

Официальный журнал Gearbox для ПК содержит обновление от **29 октября 2015 года**, в котором перечислены, в частности:

- Изменения баланса с особым вниманием к Майе.
- Добавление гранаты Fastball в добычу Болла.
- Исправления оружия, заданий, интерфейса и сетевой игры.
- Закрепление ряда прежних hotfix, включая повышение вероятности выпадения легендарных предметов.

Источник: [Gearbox — PC Update / Hot Fix Information](https://support.gearboxsoftware.com/hc/en-us/articles/205280050--PC-Update-Hot-Fix-Information).

Этот список характеризует настольное обновление. Выполнение каждого перечисленного исправления в мобильном порте отдельно не проверялось.

Тот же журнал отдельно перечисляет сетевые hotfix от **9 ноября 2015 года** и **25 января 2016 года**. Дата компиляции Android-библиотеки позднее этих дат сама по себе не доказывает, что соответствующие изменения включены в мобильные ресурсы или код. На ПК hotfix могли применяться при подключении к сети и отличались от постоянно установленных обновлений.

## Что обнаружено в мобильном комплекте контента

- В индексе оригинального patch OBB найдено **37 постоянных карт с именами `*_P.xxx`**. По именам это локации базовой кампании и арены, включая `BanditSlaughter_P.xxx`, `CreatureSlaughter_P.xxx` и `RobotSlaughter_P.xxx`.
- В индексах оригинальных OBB не найдено имён с проверенными семействами DLC: `Orchid`, `Iris`, `Sage`, `Aster`, `Lobelia`, `Tulip`, `Lilac`, `Anemone`. Отсутствие таких имён — свидетельство состава поставки, но не полный аудит всех возможных остатков DLC внутри пакетов.
- В оригинальном `Coalesced_INT.bin`, в `WillowMenu.int`, секция `Playthrough` содержит `PLAYTHROUGH_NAME_1=Normal` и `PLAYTHROUGH_NAME_2=True Vault Hunter`.
- `PLAYTHROUGH_NAME_3` в проверенной исходной английской конфигурации отсутствует.

Следовательно, номер игровой ветки и комплект доступного контента нужно учитывать раздельно. Эта мобильная поставка не эквивалентна полному ПК-комплекту 1.8.4 со всеми DLC. Отсутствие DLC-карт или названия третьего прохождения не доказывает более раннюю версию кода.

## Вопросы для будущего эксперимента с переносом DLC

Эти пункты являются планом отдельного исследования, а не уже подтверждёнными возможностями порта:

1. Зафиксировать версию ПК-донора и конкретный DLC. Ветка 1.8.4 — исходная точка для сравнения; контент обновлений 2019 года потребует отдельной оценки различий.
2. Сопоставить заголовки, таблицы объектов, зависимости и сериализацию ПК-пакетов с мобильными `833 / 46`. Совпадение номера формата само по себе не гарантирует совместимость.
3. Установить, какие классы и нативные функции DLC уже есть в Android-библиотеке и `WillowGame.xxx`, а какие отсутствуют. В частности, наличие полноценного кода UVHM, Гейдж и Крига этим исследованием не определялось.
4. Исследовать регистрацию DLC, определения пакетов, проверку доступности контента, Fast Travel и условия появления миссий.
5. Проверить платформенные различия cooked-ресурсов: текстуры, шейдеры, материалы, аудио и ссылки между пакетами. Простое копирование `CookedPCConsole` в мобильную поставку не проверялось.
6. Отдельно проверить загрузку карты, запуск и завершение миссий, выдачу предметов, сохранение и повторную загрузку. Факт загрузки одной карты не подтверждает работоспособность всего DLC.

## Ограничения исследования

Определена версия исходной игровой ветки и проверены перечисленные признаки оригинальной поставки. Не проводились перенос DLC, запуск DLC-карт, полная проверка баланса, сетевых hotfix или совместимости сохранений. Совпадение версии 1.8.4 не является гарантией бинарной совместимости ПК- и Android-ресурсов.
